# Data Science Python Projects

A collection of interactive and educational Python projects developed by **Francesco Scolz**, designed to explore and deepen various scientific fields, from basic mathematical modeling to advanced **Data Science**, primarily using the **Jupyter Notebook** environment.

The projects are focused on data analysis, predictive modeling, and decision-making optimization. Some worthy examples:

*   **[Taiwan Robust and Explainable Credit Lend](https://github.com/FreyFlyy/python-projects/tree/main/data-science-projects/taiwan-robust-explainable-credit-lend-(ENG)):** An end-to-end ML pipeline for **credit default prediction**, entirely business driven and tested under real world hypotheses and noisy scenarios, achieving a profit uplift compared to the baseline in more than **75% of the cases**, with a mean of almost **$7M/year** on a **2'000'000** estimated customer base within confidence interval
*   **[Udine Precipitation Predictor](https://github.com/FreyFlyy/python-projects/tree/main/data-science-projects/previsione-meteo-udine-(ITA)):** A model based on **RandomForestClassifier** to predict rain in Udine (S. Osvaldo) with a measured accuracy of 71.35%.
*   **[Youth Stress Predictor](https://github.com/FreyFlyy/python-projects/tree/main/data-science-projects/youth-stress-predictor-(ENG)):** A predictive pipeline to estimate the **type of stress** in youth via surveys; includes an interactive demo hosted on HuggingFace.

*   **Languages:** Python 3.12+
*   **Main Libraries:**
    *   Machine Learning/Deep Learning: *PyTorch, Scikit-learn*
    *   Data Analysis: *Pandas, Numpy, Shap*
    *   Visualization: *Matplotlib, Seaborn*

## Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/FreyFlyy/data-science-projects.git
    ```
2.  **Install dependencies:** (Use of a virtual environment is recommended)
    ```bash
    pip install -r requirements.txt
    ```
    *(Note: individual `requirements.txt` and instruction files are located within each project folder).*
